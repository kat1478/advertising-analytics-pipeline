# Project Charter

## Project name

Advertising Analytics Data Pipeline

## Goal

Build a realistic, recruiter-friendly data engineering portfolio project that demonstrates:

- Python pipeline orchestration;
- SQL analytical transformations;
- DuckDB-based local warehouse design;
- data quality validation;
- automated testing;
- CI workflow;
- business-readable advertising insights.

## Non-goals

- Training a machine learning model.
- Using real user data.
- Committing secrets, local agent instructions, or generated databases.
- Overengineering infrastructure before the core pipeline works.

## Target audience

Recruiters and hiring managers for Data Engineer, Analytics Engineer, and AI/Data roles.

## Design principles

1. Prefer clarity over cleverness.
2. Keep transformations SQL-first.
3. Keep Python orchestration simple and testable.
4. Validate data before trusting metrics.
5. Make every README claim verifiable in the repository.
6. Keep public history clean and professional.
